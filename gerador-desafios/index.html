No Microsoft Excel, qual função soma valores?

A) MÉDIA
B) MÁXIMO
C) SOMA
D) CONT.SE

COMENTÁRIO:
A função SOMA adiciona os valores do intervalo.

PARA MEMORIZAR:
SOMA = somar.
